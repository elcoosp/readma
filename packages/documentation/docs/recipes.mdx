# Recipes

Ready-to-adapt configurations. All of them are declarative data files — if
a field does not autocomplete, check the
[config reference](/docs/config/reference).

## Deno monorepo with JSR packages

The shape Readma itself uses:

```yaml
# readma.yaml
title: My workspace
description: A short description of the workspace
repo: owner/my-workspace
language: ts
packageRegistry: jsr
author: owner
contact:
  email: owner@gmail.com
  x: owner
links:
  doc: https://my-workspace.dev
images:
  logo: images/logo.png
  screenshot: images/screenshot.gif
license:
  id: MIT
issueTemplates:
  bug: bug-report.yml
  feature: feature-request.yml
badges:
  style: flat-square
  disabled:
    - issues
toc:
  backToTop: false
```

```
readma/
  about.md
  features.md
  getting-started.md
  installation.md
  usage.md
  roadmap.md
  contributing.md
  acknowledgments.md
```

Every member package can override any of those files by dropping its own
`readma/` directory next to its manifest.

## Single npm package

```yaml
title: my-cli
description: A tiny command line tool
repo: owner/my-cli
contact:
  email: owner@gmail.com
badges:
  disabled:
    - fork
```

```
readma/
  about.md
  features.md
  usage.md
```

The installation section is auto-generated from the detected registry; drop a
`readma/installation.md` to replace it.

## Rust workspace

```yaml
title: my-crate
repo: owner/my-crate
language: rs
packageRegistry: crates.io
license:
  id: Apache-2.0
```

```
readma/
  about.md
  usage.md
```

The `msrv` badge appears automatically for `language: rs`, and the
installation snippet becomes `cargo add my-crate`.

## Minimal readme, no badges and no contact

A readme with a title, some sections and nothing else:

```yaml
title: Notes
```

```
readma/
  about.md
```

No repo slug means no badges, no issue links and no raw image urls: exactly
the header, the table of contents and your content.

## Retitle a generated section

```yaml
sections:
  license:
    title: Legal
  contact:
    title: Get in touch
  roadmap:
    hide: true
```

## Custom ordered sections

```
readma/
  usage.md
  20-benchmarks.md
  30-comparison.md
```
