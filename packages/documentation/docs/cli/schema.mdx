# `schema`

```bash
deno run -A jsr:@readma/cli schema
```

Prints the JSON Schema (draft 2020-12) describing the whole readma config —
the same shape documented in the
[configuration reference](/docs/config/reference). Only `title` is required,
everything else is optional.

## What it is for

The config is a data file (`readma.yaml`, `.yml`, `.toml` or `.json`), so the
JSON schema is the primary editor integration: reference it with the
`$schema` key to get validation and autocompletion while you edit.

## Usage

```bash
# Save it next to your config
deno run -A jsr:@readma/cli schema > readma.schema.json
```

Then reference it:

```yaml
$schema: ./readma.schema.json
title: My project
repo: owner/my-project
```

Example excerpt:

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "Readma config",
  "type": "object",
  "required": ["title"],
  "properties": {
    "title": { "type": "string", "description": "Title of the readme" },
    "repo": {
      "type": "string",
      "description": "Github slug of the project, e.g. owner/name"
    }
  }
}
```
