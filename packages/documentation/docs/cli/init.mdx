# `init`

```bash
deno run -A jsr:@readma/cli init [options]
```

Scaffolds two things at the project root:

1. a `readma.yaml` config, pre-filled with everything Readma can detect
   locally:
   - **git remote** — parsed from `git config --get remote.origin.url`, both
     SSH (`git@github.com:user/repo.git`) and HTTPS forms, into the `repo`
     slug and title,
   - **language** — `ts` or `rs`, from
     [workspace detection](/docs/workspace-detection),
   - **package registry** — `jsr`, `npm` or `crates.io`,
   - **license** — SPDX identifier detected from the license file;
2. a `readma/` content directory holding starter markdown files:
   `about.md`, `features.md`, `usage.md` and `roadmap.md`.

## Options

| Option             | Type     | Description                                       |
| ------------------ | -------- | ------------------------------------------------- |
| `--force`          | flag     | Overwrite an existing config file                  |
| `--config <path>`  | `string` | Target config file path, e.g. `configs/readma.yaml` |
| `--dry-run`        | flag     | Print the generated config without writing it      |

## Behavior

- Without `--force`, `init` refuses to overwrite an existing config and
  throws.
- Existing content files are never overwritten, even with `--force`: only
  the missing starters are created.
- With `--dry-run`, the config content is printed to stdout and nothing is
  written.
- When the git remote or license cannot be detected, safe placeholder values
  (`your-github-username`, `MIT`) are used instead of failing.

## Example output

```yaml
# Readma configuration, see https://readma.vercel.app for the full reference.
# Every field except title is optional: drop what you do not need.
title: my-project
description: A short description of your project
repo: your-github-username/my-project
language: ts
packageRegistry: jsr
license:
  id: MIT
```

:::tip
Right after `init`, `deno run -A jsr:@readma/cli validate` tells you which
fields still need your attention, and `gen --stdout` previews the readme.
:::
