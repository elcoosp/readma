# `validate`

```bash
deno run -A jsr:@readma/cli validate
```

Loads the config and reports every problem it can find **before** you run
`gen` or push to CI. Each issue is logged with its level; the command exits
with code `1` when at least one error-level issue exists.

## Options

| Option            | Type     | Description                       |
| ----------------- | -------- | --------------------------------- |
| `--config <path>` | `string` | Path to the config file            |

## What is checked

### Config data (errors)

The config object itself is validated: a non empty `title`, the `owner/name`
shape of `repo`, enum values for `language`, `packageRegistry` and
`badges.style`, and the types of every nested object. Issues are reported
with their exact path:

```
[error] badges.style: expected one of for-the-badge, social, flat, flat-square, plastic
```

### Referenced files (errors)

| Field                      | Resolved against           |
| -------------------------- | -------------------------- |
| `images.logo`              | Project root               |
| `images.screenshot`        | Project root               |
| `issueTemplates.bug`       | `.github/ISSUE_TEMPLATE/`  |
| `issueTemplates.feature`   | `.github/ISSUE_TEMPLATE/`  |
| `coc`                      | Project root               |
| `license.file`             | Project root               |

A missing config file, a broken yaml/toml/json payload or a custom
`content.dir` pointing nowhere are errors too.

### Content directory

- **error** — a front matter block that does not parse or holds wrong types,
- **warning** — an empty content file, its section will be omitted,
- **warning** — a duplicate section id (`10-faq.md` and `faq.md`),
- **warning** — a leftover legacy `.mdx` file, Readma v2 only reads `.md`.

### Warnings

- A `license.id` set without a `LICENSE.txt` next to the config (pass
  `license.file` if your license lives elsewhere).

## Example output

```bash
$ deno run -A jsr:@readma/cli validate
Config at /path/to/repo/readma.yaml is valid

$ deno run -A jsr:@readma/cli validate
[error] Logo image not found at /path/to/repo/images/logo.png
[warn] Content file /path/to/repo/readma/draft.md is empty, its section will be omitted
```

:::note
`validate` checks the config and its inputs, not the rendered output. To
catch stale READMEs, use `gen --check` instead — the two are complementary
and both belong in CI.
:::
